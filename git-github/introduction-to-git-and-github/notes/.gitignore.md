## What Is a `.gitignore` File?

A `.gitignore` file is used to tell Git which files and folders should be ignored and not tracked by the repository.

This is useful for excluding:
- temporary files
- build files
- dependency folders
- operating system files
- sensitive information

Ignoring unnecessary files helps keep the repository clean and organized.

## Example

```text
node_modules/
.env
*.log
```

In this example:
- `node_modules/` ignores the dependencies folder
- `.env` ignores environment variable files
- `*.log` ignores all log files

## Practical Example

```bash
touch .gitignore
```

This command creates a new `.gitignore` file in the current directory.
