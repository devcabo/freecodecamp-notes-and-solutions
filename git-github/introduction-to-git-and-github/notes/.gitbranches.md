# Git Branches

## What Is a Branch?

A branch is a separate workspace inside a Git repository where developers can safely create, test and modify features without affecting the main project until the changes are merged.

Branches are commonly used to:
- develop new features
- fix bugs
- test ideas
- work collaboratively

The default branch is usually called `main`.

---

## Create a New Branch

```bash
git branch feature/login-page
```

This command creates a new branch called `feature/login-page`.

---

## Switch to Another Branch

```bash
git checkout feature/login-page
```

This command changes the current working branch.

Modern Git versions also support:

```bash
git switch feature/login-page
```

---

## Create and Switch to a Branch

```bash
git checkout -b feature/login-page
```

This command:
- creates a new branch
- immediately switches to it

Modern alternative:

```bash
git switch -c feature/login-page
```

---

## View Existing Branches

```bash
git branch
```

Example output:

```text
* main
  feature/login-page
```

The `*` symbol indicates the current active branch.

---

## Merge a Branch

```bash
git merge feature/login-page
```

This command merges the changes from `feature/login-page` into the current branch.

---

## Practical Workflow Example

```bash
git checkout -b feature/navbar
```

Create and switch to a new branch.

```bash
git add .
git commit -m "feat: create navigation bar"
```

Save the new feature changes.

```bash
git checkout main
git merge feature/navbar
```

Merge the completed feature into the main branch.

---

## Real-World Example

```text
A development team creates separate branches for each feature being developed.

This allows multiple developers to work on different parts of the project simultaneously without affecting the main production branch.
```
